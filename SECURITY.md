---

## 🚨 Reporting a Vulnerability

If you discover a security vulnerability, rule bypass, or privilege escalation vector in ToolGuard:

1. **Do not disclose it publicly** via GitHub issues or discussions.
2. Send a report directly to **navdeep19619@gmail.com** with:
   - A description of the issue and potential impact.
   - Exact steps or command payload to reproduce the bypass.
   - Suggested mitigations if known.
3. We will acknowledge receipt within 48 hours and work on a fix before public disclosure.
